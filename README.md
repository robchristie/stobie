# Polyorama

Polyorama is an Apache-2.0-licensed experimental Rust framework layer for
GPU-driven analytical workspaces on native and WebGPU-capable browsers.

The first runnable application is **Analytical Workspace Lab**. See
[`docs/vertical-slice-goal.md`](docs/vertical-slice-goal.md) for its contract and
[`docs/vertical-slice-report.md`](docs/vertical-slice-report.md) for verification
evidence once the slice is complete.

```sh
cargo xtask verify
```
